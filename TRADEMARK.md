The **Slate** name and the Slate logo identify this project and its official distributions. They
are trademarks of the project maintainers and are **not** licensed to you by the AGPL-3.0 licence
that covers the code.

This policy exists so that users can tell the official project from forks, and so improvements can
be shared without confusion about who endorses them. It is intentionally close to the trademark
policies of other open-source projects.

## You may, without asking

- Use the name **Slate** truthfully to refer to this project, its code, or an unmodified copy of it
  — for example "Slate is a handwriting-first AI whiteboard" or "this deployment runs Slate".
- State that your project is **based on Slate** or a **fork of Slate**, in plain text, as long as the
  statement is accurate and does not imply endorsement.
- Keep the name in the source tree, package metadata, commit history, and documentation of an
  unmodified copy.
- Use the logo in a review, article, tutorial, or academic work about the project.

## You may not, without written permission

- Use the Slate name or logo as the name or branding of a **modified version** you distribute or
  operate, or of a product or service that competes with the project.
- Use the logo as your application icon, favicon, store listing image, or domain branding.
- Imply that your fork, deployment, company, or product is official, sponsored, endorsed, or
  maintained by the Slate maintainers.
- Register a domain, social account, package name, app-store listing, or trademark that is
  confusingly similar to Slate.

## Forks

If you distribute or host a modified version, you must:

1. use a different product name and a different icon/logo;
2. remove the Slate name and logo from the user-facing product (app title, splash screen, store
   listing, sign-in screen, marketing pages);
3. keep the copyright and licence notices required by AGPL-3.0;
4. make clear that your version is a fork and is not endorsed by the Slate maintainers.

You may keep "based on Slate" as a factual attribution in your README and about screen.

## This repository

This repository ships the Slate app icon set — `apps/web/public/`, `apps/web/assets/` and the
launcher and splash images under `apps/web/android/app/src/main/res/` — because a build without an
icon looks broken. Those files **are** the Slate mark.

They are nonetheless **not granted to you by the code licence**. LICENSE covers the software under
AGPL-3.0; the mark in those files stays the maintainers' trademark, the same way the project name
does. Running the unmodified code under the Slate name is allowed (see above). Distributing or hosting
a modified version with a Slate icon is not: replace every file listed above with your own mark before
you build.

## Reporting misuse

Report confusing use of the marks to the maintainers through the repository. This policy does not
limit any rights the maintainers have under trademark or unfair-competition law.
